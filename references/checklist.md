# 검증 체크리스트

검증은 AI가 자체적으로 완료합니다: 문제 발견 → 수정 → 스크린샷 재검증 순으로 진행하며, 모든 항목을 통과해야 최종 납품합니다.

## A. 자동 품질 게이트 (반드시 0 ERROR)

```bash
npm run fonts                 # 누락 글꼴 보고 → 글꼴 교체 또는 문구 수정
python3 scripts/elevenlabs.py vo    # 내레이션 있는 경우: 각 문장 OK (길이 제한 충족 + 받아쓰기 일치)
npm run mix                   # 오디오 믹싱; 내레이션 있을 때 vo_margin 출력, 음성은 음악보다 ≥ +8 dB 커야 함
python3 scripts/elevenlabs.py check-mix   # 내레이션 있는 경우: 최종 믹싱 음성 텍스트 변환 검증, 전체 일치율 ≥ 0.97 및 전 문장 명확성 확인
npm run check:assets          # 파일 누락 / 이미지 과소·과대 / 글꼴 누락 검사
npm run lint                  # eslint + tsc
```

영상 렌더링 완료 후:

```bash
python3 scripts/check_video.py out/final-4k.mp4 --scale 2   # 규격, 로그 에러, 음량(LUFS), 씬별 프레임 추출 검사
```

렌더링 로그에 `cannot be decoded`와 같은 오류가 나타난 경우, 렌더링이 "성공"으로 표시되더라도 실패로 간주하고 조치해야 합니다 (`references/pitfalls.md` 참조).

## B. 이미지/프레임 검수 (매 라운드마다 수행)

```bash
node scripts/stills.mjs --scenes && python3 scripts/sheet.py   # 각 씬의 35% / 85% 시점 두 프레임 캡처
node scripts/stills.mjs 11.4 11.6 18.7                          # 주요 트랜지션, 비트 드롭, 텍스트 완성 순간 추가 캡처
```

`out/sheet.jpg`를 열고, 의심스러운 컷은 원본(`out/stills/*.jpg`)을 확대하여 확인합니다. 항목별로 확인:

**텍스트**
- [ ] 모든 텍스트가 배경과 충분한 대비를 이룸: 밝은 배경 위의 밝은 그라데이션 텍스트, 광원 효과 중심의 흰색 텍스트, 배경과 유사한 색상의 텍스트는 모두 수정(색상 어둡게 변경, 외곽선/글로우 추가, 배경 어둡게 처리).
- [ ] 텍스트 오버플로, 잘림, 비정상적 줄바꿈 없음; 한글 단어 중간에서 어색하게 끊기지 않음 (예: "다섯 가지 핵심원 / 리" 같은 경우 레이아웃이나 폰트 크기 조정).
- [ ] 가려진 텍스트: 카드가 겹쳐질 때 뒤쪽 카드의 글자가 가려지지 않는지 확인.
- [ ] 숫자, 명칭, 웹사이트 URL이 모두 정확하며 조사 노트와 일치함.
- [ ] 자체 작성한 모든 설명 문구("순수 SVG", "배경음악 포함", "7가지 스타일", "최근 화제" 등의 한정어)가 원본 글/공식 페이지의 실제 내용과 일치함. 확인되지 않으면 삭제.
- [ ] 영상 위 텍스트(특히 화면이 빠르게 명암 전환되는 몽타주 구간)에 텍스트 그림자뿐만 아니라 어두운 배경 바/오버레이가 적용되어 있는지 확인.

**스토리라인** (`AGENTS.md` 원칙 4 참조)
- [ ] 비전문가 재진술 테스트: `timing.json`의 내레이션 원고만 읽고 순서대로 5문장의 "인과관계 맥락"을 정리할 수 있는지 확인. 앞 문장과 자연스럽게 이어지지 않거나 사전 지식이 필요한 단어가 있다면 문장을 수정하거나 설명 카드를 추가.
- [ ] 첫 번째 내레이션과 첫 화면의 큰 타이틀만 따로 떼어놓고 봐도 "이것이 무엇이고, 어떤 일이 일어났는지" 명확히 설명됨.
- [ ] 자막과 음성이 동일한 내용을 다룸: 화면의 큰 글씨는 내레이션보다 최대 1.5초 먼저 나타날 수 있으나, 내레이션보다 늦게 나타나서는 안 됨.

**템포/리듬** (`AGENTS.md`의 "템포: 하한선 + 밀도" 참조)
- [ ] 각 텍스트가 다 읽을 수 있을 만큼 충분히 머무름: 주요 강조 구간 ≥ 1.3초, 숏컷 전환 ≥ 0.65초, 정보 씬 ≥ 3.5초.
- [ ] 웹사이트 URL/CTA가 가장 하이라이트(클라이맥스) 구간에 나타나 3초 이상 유지됨.
- [ ] 3초 시점의 스크린샷에 이미 페인포인트 또는 핵심 셀링포인트가 노출됨; 5초 전에 첫 번째 고에너지 임팩트가 발생함.
- [ ] 오프닝 0~12초 구간을 0.5초 간격으로 프레임 검토: 첫 4초 동안 화면 전환 2회 이하; 카메라 줌인 시 각 초점과 텍스트 행이 1.4초 이상 머무름.
- [ ] 1초 간격 프레임 추출(`node scripts/stills.mjs`에 0,1,2,... 전달) 후 구간별 검토: "화면에 새로운 정보가 없는" 상태가 연속 2초 이상 지속되지 않음; 순수 전환 효과는 ≤ 0.6초.
- [ ] 모든 씬의 스크린샷을 나란히 배열하여 확인: 동일한 레이아웃 형태가 연속 3회 이상 반복되지 않음.
- [ ] 총 재생 시간이 요구사항 확인서에 명시된 범위 내에 있음 (기본 45~60초).

**실제 소재**
- [ ] 각 기능 섹션마다 실제 UI 화면 캡처 또는 실제 작업물 이미지가 포함되어 있으며, 영상 전체에서 최소 8장 이상 사용됨; 8장 이상의 실제 작업물 숏컷 몽타주가 1개 이상 포함됨.
- [ ] 실제 캡처 이미지가 4K 해상도에서 선명함 (원본 너비 ≥ 표시 너비 × 2); 캡처 화면에 이벤트 배너, 플로팅 바, 개인정보(우측 상단 프로필 이미지, 사용자 이름)가 노출되지 않음.
- [ ] 캡처 이미지가 왜곡(찌그러짐/늘어남)되지 않음: 캡처 이미지가 들어간 씬마다 프레임을 확인하여 원형 프로필, 로고, 아이콘이 정원 형태를 유지하는지, 텍스트 비율이 원본보다 좁아지지 않았는지 확인.

**비주얼/연출**
- [ ] 캡처 소재가 선명하고(4K에서 번짐 없음), 크롭 위치가 적절함(핵심 요소가 잘리지 않음).
- [ ] 노출된 작품/기능이 실제로 해당 제품의 것이며 중복되지 않음 (동일 작품의 유사 스크린샷 2회 사용 금지).
- [ ] 각 씬마다 미세한 모션(마이크로 인터랙션)이 지속되어 정지 프레임(데드 프레임)이 없음; 트랜지션 전후로 블랙 스크린이나 깜빡임 에러 프레임이 없음.
- [ ] 스타일이 요구사항 확인서와 일치하며, "기본 어두운 테크풍"으로 회귀하지 않음.

**웹 플레이어 버전** (제작하는 경우)
- [ ] `npm run web` 실행 시 포스터 프레임, 로딩 프로그레스, 재생, 일시정지, 종료 화면, CTA 버튼이 정상 작동함; 재생 중 불필요한 컨트롤러가 화면을 가리지 않음.
- [ ] 사운드가 끊김 없이 한 번만 출력됨: 실제 Chrome 환경(Playwright 또는 DevTools)에서 재생을 누르고 0.25초마다 `<audio>.currentTime`을 읽었을 때 10초 동안 초당 1.0씩 안정적으로 증가하며 뒤로 튀지 않음.
- [ ] 테스트 완료 후 즉시 테스트 페이지를 일시정지하고 닫음 (테스트용 브라우저 종료).
- [ ] 사용자에게 웹 플레이어를 보여줄 때는 `npm run web:serve`를 실행한 후 시스템 기본 브라우저에서 `http://127.0.0.1:18765`를 엽니다 (`python3 -m http.server`는 오디오 Range 요청을 지원하지 않으므로 사용 금지).
- [ ] 재생 종료 후 마지막 프레임에 정지(`moveToBeginningWhenEnded={false}`), CTA 버튼이 엔딩 화면의 텍스트와 겹치지 않음.

**오디오**
- [ ] `python3 scripts/mix.py --env` 볼륨 곡선이 설계와 일치함: 진입 시점, 크레센도, 드롭 급변, 급정지, 엔딩 페이드아웃.
- [ ] 효과음(SFX) 타이밍이 화면 이벤트와 정확히 일치함 (2~3개 지점 캡처 타임스탬프와 큐 타임 대조).
- [ ] `vo` 생성이 모두 `OK`이고 `check-mix`를 통과했으며, `voice.keywords`에 브랜드명과 URL이 등록되어 있음 (`references/voiceover.md` 3절 참조).
- [ ] 내레이션 모델, 음색 설정을 변경했거나 `sts`를 켰을 때: 사용자에게 3문장 샘플을 먼저 들려주고 확인을 받았음.
- [ ] 내레이션 내용과 화면 내용이 일치함: 언급된 프로젝트, 수치가 그 순간 화면에 정확히 표시됨 (Scribe 단어별 타임스탬프 대조).
- [ ] 오프닝 음악 무드가 화면 연출과 일치함 (문제점 제기 구간은 의문/긴장감 조성, 시작부터 과도한 고에너지 지양).

## C. 납품 전 확인사항

- [ ] 완성 영상이 `<출력 디렉터리>/<프로젝트명>/`에 복사되었으며, 파일명이 한글로 되어 있음 (`홍보영상 4K.mp4`).
- [ ] `요구사항_확인서.md`의 수정 내역이 업데이트됨; `조사_노트.md`에 모든 소재의 출처가 기재됨.
- [ ] 최종 보고에 사용자가 직접 확인해야 하는 항목(사운드, 실제 데이터 정확성, 서드파티 소재 라이선스)이 명시됨.
- [ ] 제품 상태나 사례 수치가 변동될 수 있는 경우(미출시 제품, 루머, 스타 수 등) 납품 직전 재확인 후 조사 노트에 반영.
- [ ] ElevenLabs 소재를 사용한 경우 유료 플랜 여부(무료 플랜은 상업적 이용 불가), 음색 이름 및 ID, 프롬프트를 조사 노트에 명시.
