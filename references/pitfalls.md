# 시행착오 기록 (트러블슈팅 가이드)

여기에 기록된 모든 항목은 실제 제작 과정에서 직접 겪은 실패와 해결책입니다. 이상한 문제나 예기치 않은 오류가 발생하면 가장 먼저 이 문서를 확인하세요. 새롭게 겪은 문제와 해결책은 해당 카테고리에 계속 추가합니다.

## 1. 기획 및 콘텐츠

| 문제 현상 | 구체적 증상 | 해결 방법 |
|---|---|---|
| 너무 빠른 템포 | 사용자 피드백: "시청자가 내용을 소화할 수 없다" (숏컷 전환 0.45초, 정보 씬 3.6초) | `AGENTS.md`의 템포 하한선 준수. 감속 시 정보 밀집 구간을 우선 완화하고, 시각적 임팩트 구간은 스피디함 유지 |
| URL이 엔딩에만 잠깐 노출됨 | 사용자 피드백: "영상 전체에서 전체 웹사이트 주소를 볼 수가 없다" | 클라이맥스 씬에 주소창 스타일의 눈에 띄는 URL을 1회 배치하고, 엔딩 화면에 다시 노출. 웹 플레이어 엔딩에서 URL을 숨기지 않음 |
| 타사 결과물을 무단 도용할 뻔함 | 가장 보기 좋은 3D 스크린샷이 알고 보니 모델 제조사의 공식 데모였음 | 캡처 이미지의 전후 맥락을 면밀히 검증. 출처가 불분명하면 사용 배제 |
| 문서 앞부분 이미지만 편식함 | 가장 완성도 높은 결과물 스크린샷이 문서 후반부 실전 데모 섹션에 있어 누락됨 | 문서 내 모든 이미지를 일괄 다운로드한 후 밀착 시트(Contact Sheet)로 전체를 전수 검토 |
| 동일한 작품이 중복 노출됨 | 유사한 두 장의 캡처가 서로 다른 두 개의 프로젝트로 오인되어 배치됨 | 각 프로젝트당 가장 대표적인 이미지 1장만 엄선하여 배치 |
| 제품 자체에 대한 설명 부족 | 제작자 개인 이력이나 수치 지표만 너무 강조되어 정작 제품의 실체를 알 수 없음 | 모듈 조감도, 실제 인터페이스, 상세 기능/커리큘럼 목록으로 풍부함을 입증하고 개인 이력은 가볍게 언급 |
| 기본 다크 테크 스타일로 회귀 | 매번 결과물이 짙은 남색/보라색의 뻔한 미래지향적 테크풍으로 제작됨 | 스타일은 반드시 사전 인터뷰와 샘플 프레임 검토를 통해 확정하고 그 원칙을 엄수 |
| 아직 출시되지 않은 미공개 제품 | "새로 나온 Fable 5.5 홍보 영상 제작해줘"라고 했으나 공식 최신 버전은 5.1이었고 5.5는 커뮤니티 루머였음 | 사전 조사의 첫 단계는 공식 뉴스룸 확인. 공식 출처가 없으면 포지셔닝을 먼저 질의 (`references/requirements.md` 0단계) |
| 수수께끼식 의문형 오프닝 | "버전 5.1이라 적혀 있는데 답변은 딴판이다?" 같은 개그/은어성 오프닝은 비전문가가 이해 불가 | 첫 문장은 누구나 아는 일상어로 사건의 팩트를 먼저 설명하고, 밈이나 인물명은 설명 카드를 병기. 비전문가 재진술 테스트 필수 |
| 출처에 없는 수식어 임의 추가 | "순수 SVG 코드 렌더링", "BGM 포함 단편", "7가지 화풍" 등 원문 작성자가 언급하지 않은 수식어를 붙임 | 자막과 설명 문구는 원문 글 및 공식 발표에 존재하는 사실만 사용. 검증 목록에서 대조 확인 |
| 2차 인용 기사의 원본을 못 찾음 | 흥미로운 사례가 IT 뉴스 기사에만 소개되어 있고 원문 트윗/게시물이 없음 | 원본 출처를 찾을 수 없는 사례는 폐기. 동일 작업물 공유 시 원작자만 표기. 2차 기사의 날짜는 시차가 있을 수 있으므로 공식 날짜 기준 |
| 404 에러 페이지를 유출 증거로 오인 | 커뮤니티에서 특정 URL 접속 시 404가 뜬다는 것을 출시 증거로 착각 | 존재하지 않는 임의의 경로는 모두 404를 반환하므로 증거가 될 수 없음. 영상에 포함 금지 |
| 페이지네이션 마지막 번호를 전체 수량으로 착각 | "스킬 수가 341개"라고 요약되었으나 341은 마지막 페이지 번호였음 (실제는 수천 개) | 목록 페이지의 숫자는 맥락을 따져볼 것. 총 수량은 `(마지막 페이지 번호 - 1) × 페이지당 개수 + 마지막 페이지 개수`로 정확히 산출 |

## 2. 비주얼 및 그래픽

| 문제 현상 | 구체적 증상 | 해결 방법 |
|---|---|---|
| 텍스트와 배경 색상이 겹침 | 하늘색 배경 위의 시안 그라데이션 글자, 밝은 광원 위의 흰색 자막 가독성 저하 | 텍스트 색상을 어둡게 하거나 외곽선/그림자(`filter: drop-shadow`) 적용, 또는 텍스트 영역 배경 어둡게 처리 |
| 좁은 카드에서 타이틀 줄바꿈 깨짐 | "다섯 가지 핵심원 / 리"처럼 단어 중간에서 어색한 줄바꿈 발생 | 세로쓰기(`writing-mode: vertical-rl`)를 적용하거나 카드 가로폭을 넓히고 카드 개수를 조정 |
| 부채꼴/스택 카드의 상호 가림 | 뒤쪽 카드가 앞쪽 카드의 핵심 텍스트를 가려버림 | 겹침 간격을 넓히거나 텍스트가 항상 노출 영역에 오도록 배치. 프레임 검수 시 확인 |
| 저해상도 이미지 확대 번짐 | 180×208 저화질 스크린샷이 4K 화면에서 심하게 뭉개짐 | `check_assets.py`로 사전 감지하여 고해상도 원본으로 교체 |
| 밋밋한 시스템 폰트 | 사용자 피드백: "테크 감성이 느껴지지 않는다" | 타이틀은 스타일에 부합하는 개성 있는 헤드라인 폰트로 변경, 본문만 가독성 높은 시스템 폰트 유지 |
| 텍스트 오버플로 | 통계 카드의 서브 타이틀이나 범례 텍스트가 컨테이너 밖으로 삐져나옴 | 고정 너비 지정 + `whiteSpace: nowrap` 적용, 검수 시 작은 글씨 집중 점검 |
| 동색 요소와 텍스트의 겹침 | 브랜드 블루 슬로건 글자 바로 뒤에 동일한 블루 아이콘이 겹쳐 글자가 파인 것처럼 보임 | 모션 요소와 텍스트의 궤적이 겹치지 않도록 레이아웃 재배치 |
| 등각 지도에서 랜드마크가 경로를 가림 | 높은 타워 그래픽이 이동 경로의 코너를 가려 마우스 커서가 건물 벽에 붙은 것처럼 연출됨 | 랜드마크를 경로 뒤쪽 블록으로 배치하여 경로와 커서가 항상 전면에 보이도록 수정 |
| 영문 대형 타이틀 줄바꿈 추락 | "Claude Fable 5.5"가 바인더 가로폭을 초과하여 "5.5"만 아랫줄로 떨어져 도장을 가림 | 대형 타이틀은 `whiteSpace: nowrap`을 기본 적용하고 폰트 너비를 사전에 계산하여 마진 확보 |
| 몽타주 자막이 밝은 배경에 묻힘 | 신문 1면이나 스테인드글라스처럼 밝은 영상 위에서 흰색 그림자 글자가 안 보임 | 영상 위 텍스트에는 어두운 반투명 배경 바(`rgba(10,9,8,0.82)`)를 필수로 깔고 상단 그라데이션 추가 |
| 캡처 소재의 해상도 부족 | 썸네일 원본이 너무 작아 4K 화면에서 흐릿함 | 프레임과 UI 카드는 코드로 직접 그리고(실제 텍스트 반영), 원본 해상도가 충분한 이미지만 선별 배치 |
| 손그림 획이 점선으로 끊어짐 | SVG 드로잉 애니메이션 시 viewBox 비율 왜곡으로 인해 스트로크 대시 길이가 어긋남 | 선 그리기 애니메이션 구현 시 픽셀 단위 실제 길이를 `getLength`로 정확히 측정한 뒤 적용 |
| 모든 웹 캡처 이미지가 가로로 찌그러짐 | 브라우저 창에서 스크린샷 확대 시 Tailwind의 `img { max-width: 100% }`로 인해 가로만 압축됨 | 템플릿의 `index.css`에 `img, video { max-width: none; }` 추가. 원본 가로세로 비율을 유지하는 프레임 컴포넌트 사용 |

## 3. 사운드 및 오디오

| 문제 현상 | 구체적 증상 | 해결 방법 |
|---|---|---|
| 오프닝 음악의 어색함 | 악절 중간에서 시작하거나 저음 드론 사운드가 BGM의 조성을 방해함 | 마디 선 위에서 음악 시작, `build_in` 점진적 진입 적용, 불필요한 합성 드론 제거 |
| 템포 변경 시 효과음 싱크 이탈 | `mix.py`에 초 단위 숫자가 하드코딩되어 모션 수정 시 타이밍이 틀어짐 | 모든 효과음 타이밍은 `timing.json`의 파라미터에서 자동 계산하도록 변경 |
| 청각적 판단 불가 | AI는 소리를 직접 들을 수 없어 주관적 느낌을 알 수 없음 | `music.py bars`, `mix.py --env`로 파형과 에너지를 수치 검증하고, 최종본은 사용자가 직접 청취하도록 안내 |
| 중간에 뚝뚝 끊기는 음원 | 에너지 평균은 높으나 매 마디 후반부에 무음(-79 dB)이 발생하는 음원 | 0.1초 윈도우로 -30 dB 이하 무음 구간 비율을 사전 검사하여 탈락 처리 |
| 문제점 오프닝에 클럽 EDM 매칭 | 페인포인트를 토로하는 진지한 장면에 시작부터 시끄러운 댄스 음악이 흘러나옴 | 음악 무드는 스토리라인을 따라야 함: 시작은 긴장/의문 톤으로, 브랜드 폭발 시점에 비트 폭발 |
| AI 작곡 세부 시간 오차 | 프롬프트상 전주 4.3초를 요청했으나 모델이 7.6초 길이로 생성함 | 실제 생성된 파일의 그리드를 측정하여 화면 타이밍을 음원에 맞게 미세 조정 |
| ElevenLabs 무료 플랜 제한 | 작곡 API는 402 반환, 효과음은 상업적 이용 불가 | 사전 플랜 확인 후, 유료 플랜으로 전환하여 상업용으로 재추출 |
| 1회성 효과음의 지속시간 부족 | 앰비언트 사운드가 2초 만에 감쇠되어 씬 전체를 채우지 못함 | 배경 지속음은 `--loop` 옵션과 `continuous, no silence` 프롬프트로 루프 생성 |
| 라이저(Riser)의 피크 위치 오류 | 볼륨이 점점 커져야 하는데 생성된 음원의 피크가 오프닝 0.3초에 위치함 | 프롬프트에 `grows steadily and ends exactly at its peak` 명시 후 파형 엔벨로프 검증 |
| 내레이션 음성 모델 속도 고정 | v4 모델은 속도 파라미터를 지원하지 않아 시간 조절 불가 | 씬 길이에 맞춰 글자 수를 엄격히 통제하고, 초과 시 문장을 과감히 축약 |
| 내레이션이 음악에 묻힘 | 음악이 너무 커서 고에너지 구간에서 목소리가 잘 안 들림 | 기본 `rmsDb -13`, `duckDb -9` 설정으로 보컬 마진이 항상 ≥ +8 dB 이상 유지되도록 믹싱 |
| 복제 음성(Voice Clone) 발음 왜곡 | stability 0.5에서 고유명사나 특정 어휘를 엉뚱하게 발음함 | stability를 0.85로 높이고 `--takes 4`로 복수 생성 후 최적 결과 자동 채택 |
| 브랜드명 오독 발생 | STT 전체 유사도는 0.90으로 통과 판정이 났으나 핵심 브랜드명 한 글자가 틀림 | 브랜드명과 URL을 `voice.keywords`에 등록하여 단어 누락 시 `CHECK_WORD` 에러 유발 |
| 음성에 거슬리는 에코 잔향 발생 | 문장 끝에 긴 리버브 꼬리가 남아 음악과 섞이면서 울림 현상 발생 | 잔향 시간(`tail_ms`)을 측정하여 250ms 초과 시 모델이나 음색 교체 |

## 4. 빌드, 렌더링 및 시스템

| 문제 현상 | 구체적 증상 | 해결 방법 |
|---|---|---|
| 4K 렌더링 시 이미지 디코딩 실패 | 로그에 `The source image cannot be decoded`가 다수 발생했으나 렌더링은 완료로 뜸 | 대형 이미지가 동시 노출되는 씬은 축소본(표시폭 × 2)을 별도 준비하고 동시 실행 스레드 수 감축 |
| 시간 계산 시 부동소수점 오차 | `78.4 * 60 = 4704.000000000001`로 인해 프레임 오차 발생 | `Math.round(timing.duration * fps)`로 정수 변환 처리 |
| 패키지 설치 시 ERESOLVE 충돌 | React 19 관련 버전 호환성 문제로 npm install 중단 | 템플릿 package.json 및 lockfile 버전을 명시적으로 고정 |
| 웹 플레이어 오디오 중복 재생 | 브라우저 프레임 드랍 시 Audio 노드가 중복 생성되어 에코 발생 | 웹 플레이어에서는 일반 HTML5 `<audio>`를 마스터 클록으로 삼고 화면이 오디오를 추적하도록 구현 |
| 렌더링 중 믹싱 파일 덮어쓰기 | 렌더링 진행 중에 새 믹싱을 실행하여 파일 손상 발생 | 렌더링이 완전히 종료된 후 ffmpeg으로 오디오 트랙만 안전하게 교체 |
| 폰트 미적용 및 레이아웃 번짐 | 번들러 트리쉐이킹으로 인해 글로벌 폰트 CSS가 누락됨 | 진입점 파일에서 명시적 import 유지 및 폰트 렌더링 확인 |
| AI 생성 이미지 4K 블러 | 1280×720 이미지를 4K로 늘려 흐릿함 | Real-ESRGAN으로 4배 업스케일링 후 배치하여 선명도 유지 |
