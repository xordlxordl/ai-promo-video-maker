# 비주얼 스타일 방향 및 내러티브 구조 메뉴

이 문서는 **선택 가능한 메뉴이지 고정된 기본값이 아닙니다**. 모든 제품은 고유한 분위기, 타깃 시청자, 보유 소재에 따라 새롭게 조합되어야 하며, 사용자가 샘플 프레임을 확인한 후 최종 결정합니다. 여러 스타일을 믹스매치할 수도 있고, 메뉴에 없는 독창적인 방향을 새롭게 창작할 수도 있습니다.

방향을 정할 때 먼저 다음 세 가지 질문에 답해 보세요:
1. **제품의 고유한 톤앤매너**는 무엇인가? (전문적이고 신뢰감 있음 / 젊고 유쾌함 / 프리미엄 미니멀 / 긱하고 하드코어 / 따뜻하고 친근함)
2. **가장 설득력 있는 핵심 소재**는 무엇인가? (실제 UI 스크린샷 / 실제 제작된 결과물 / 압도적인 수치 데이터 / 유저 스토리 / 캐릭터 IP)
3. **시청자가 이 영상을 어디서 보는가?** (유튜브 16:9 가로 화면 / 릴스·쇼츠 9:16 세로 화면 / 공식 홈페이지 랜딩페이지 루프 / 컨퍼런스 키노트 대형 스크린)

## 비주얼 스타일 방향

각 방향별 특징: 적합한 제품, 비주얼 연출, 모션 언어, 폰트, 사운드, Remotion 구현 포인트를 정리합니다.

### 1. 시네마틱 트레일러 (영화 예고편 풍)
- **적합 대상**: '중대 발표', 혁신적 기술이라는 임팩트를 주고 싶은 제품, 대형 튜토리얼, 플랫폼 서비스.
- **비주얼**: 다크 톤, 볼류메트릭 라이트(빛줄기 효과), 필름 그레인, 비네팅, 시네마스코프 레터박스, 브랜드 메인 컬러 1종 + 포인트 컬러 1종.
- **모션**: 정적 상태에서 폭발적 에너지로 이어지는 극적인 대비; 다이내믹 줌인/아웃, 3D 원근 투시, 임팩트 플래시, 화면 흔들림(쉐이크), 빠른 컷 전환 몽타주.
- **폰트**: 굵직한 지오메트릭 고딕/헤드라인 폰트 (Pretendard Black, 티머니 둥근바람 등).
- **사운드**: 억누른 인트로 → 크레센도 → 묵직한 베이스 드롭; 다량의 라이저(riser), 웅장한 우시(whoosh), 서브 베이스 임팩트.
- **구현**: `impulse`로 플래시 화이트 및 타격감 있는 스케일링, `shake`로 화면 흔들림, CSS 3D(`perspective` + `rotateX/Y`)로 카메라 무빙 구현.

### 2. Q버전 카툰 / 마스코트 캐릭터
- **적합 대상**: 대중, 젊은 층, 학생 대상의 생산성 도구 및 앱; 마스코트 IP가 있거나 제작 가능한 경우.
- **비주얼**: 고채도 캔디 컬러, 굵은 외곽선, 라운드 코너, 대두 캐릭터, 스티커 느낌의 오브젝트, 밝은 톤 배경.
- **모션**: 탄성 바운스(`EASE.back` / Remotion `spring`), 스쿼시 & 스트레치, 캐릭터 표정 변화, 요소들이 톡톡 튀어나오는(Pop) 경쾌한 템포.
- **폰트**: 둥근 서체 또는 손글씨 느낌의 볼드체.
- **사운드**: 경쾌한 우쿨렐레 / 휘파람 / 일렉트로 팝, 뽁/띵/슈웅 등의 귀여운 효과음.
- **구현**: AI 이미지 생성 도구로 메인 캐릭터를 확정한 후, 투명 배경 PNG로 다양한 표정/모션을 생성; CSS transform으로 캐릭터의 호흡, 점프, 흔들림 루프 구현.

### 3. 애플 키노트식 극단적 미니멀리즘
- **적합 대상**: 감각적인 디자인, 하이엔드 포지셔닝 제품, 하드웨어, 전문 소프트웨어.
- **비주얼**: 순백색 또는 딥블랙의 광활한 여백, 단일 포커스, 초대형 헤드라인 타이포, 중앙 배치된 제품 UI/하드웨어, 극도로 얇은 라인.
- **모션**: 완만하고 정교하며 절제된 움직임; 단어가 하나씩 우아하게 등장, UI가 부드럽게 슬라이드인되며 깜빡임이나 흔들림 지양.
- **폰트**: 산세리프(SF Pro, Pretendard 계열), 극단적인 폰트 크기 및 두께 대비.
- **사운드**: 피아노 또는 앰비언트 일렉트로닉, 극소량의 섬세한 효과음.
- **구현**: 긴 호흡의 `EASE.inOut` 이징 곡선, 한 화면에 오직 하나의 메시지만 전달 (단, 템포 하한선은 준수).

### 4. 실제 인터페이스 쇼케이스 (제품 워크스루)
- **적합 대상**: 기능 그 자체가 강력한 셀링포인트인 SaaS, 생산성 툴, 개발자 도구.
- **비주얼**: 실제 UI 스크린샷을 브라우저/디바이스 프레임에 담고, 돋보기 포커스, 마우스 커서 클릭, 하이라이트 박스 활용.
- **모션**: 실제 작업 흐름 재현 — 타이핑, 클릭, 드래그, 결과물 출력; 커서를 따라 카메라가 부드럽게 줌인.
- **폰트**: 제품 UI 자체의 시스템 폰트 + 간결한 설명 텍스트.
- **사운드**: 차분한 일렉트로닉 비트, 키보드 타건음, 마우스 클릭음이 조작 화면과 1:1로 정밀하게 싱크.
- **구현**: `typed()`를 이용한 타이핑 모션; 스크린샷을 분해하여 레이어(배경 + 움직이는 카드)로 재구성.

### 5. 핸드드로운 드로잉 / 화이트보드 해설
- **적합 대상**: 복잡한 개념을 쉽게 설명해야 하는 교육/학습 플랫폼, 따뜻하고 친근한 브랜드.
- **비주얼**: 종이 질감(텍스처), 손그림 라인아트, 마커펜 컬러 블록, 손글씨 메모.
- **모션**: 라인 드로잉(SVG stroke-dashoffset), 실시간으로 그림이 그려지는 효과, 프레임별 미세한 지터(보일링 라인).
- **폰트**: 자연스러운 손글씨체.
- **사운드**: 어쿠스틱 기타, 사각거리는 펜 촉 소리.
- **구현**: `@remotion/paths`의 `evolvePath`로 선 그리기; 난수와 프레임 번호로 선 떨림 효과 구현.

### 6. 레트로 픽셀 아트 / 8-bit 아케이드 게임
- **적합 대상**: 인디 게임, 개발자 커뮤니티, 긱(Geek) 문화 기반 제품, 재미있는 유틸리티.
- **비주얼**: 픽셀 폰트, 레트로 팔레트, CRT 스캔라인, 게임 UI(체력 게이지, 경험치 바, 퀘스트 클리어).
- **모션**: 프레임 단위 스텝 전환(부드러운 보간 배제), 픽셀 폭발 효과, 'LEVEL UP' 배너 연출.
- **폰트**: 비트맵 픽셀 폰트 (둥근모꼴 등 오픈소스 한글 픽셀 폰트).
- **사운드**: 칩튠(Chiptune), 8비트 레트로 아케이드 효과음.
- **구현**: 애니메이션 계산 시 시간을 12fps로 양자화(Quantize), `image-rendering: pixelated` 적용.

### 7. 사이버펑크 네온 / 글리치
- **적합 대상**: 첨단 AI, 보안, 딥테크, 블록체인 등 하드코어 기술 제품.
- **비주얼**: 다크 백그라운드 위 네온(마젠타 / 사이언), 글리치 왜곡, 스캔라인, HUD 인터페이스, 코드 매트릭스.
- **모션**: RGB 채널 분리, 깜빡임, 슬라이스 어긋남, HUD 수치 고속 카운팅.
- **사운드**: 다크 신스웨이브(Dark Synthwave), 노이즈 글리치 효과음.

### 8. 에디토리얼 매거진 / 스위스 그래픽 스타일
- **적합 대상**: 미디어, 콘텐츠 플랫폼, 브랜딩 중심 서비스.
- **비주얼**: 모듈러 그리드 시스템, 파격적인 대형 타이포, 볼드한 컬러 블록, 과감한 사진 크롭, 넘버링.
- **모션**: 레이아웃 블록의 슬라이딩 이동, 텍스트 마스크 디졸브, 솔리드 컬러 닦아내기(Wipe) 전환.
- **사운드**: 리듬감 있는 로파이(Lo-Fi) / 재즈 힙합 / 딥 하우스.

### 9. 3D 점토(Clay) / 클레이메이션
- **적합 대상**: 라이프스타일, 키즈, 감성적이고 따뜻한 서비스.
- **비주얼**: 클레이/플라스틱 질감의 3D 공간 및 오브젝트, 부드러운 소프트 섀도우, 얕은 심도(블러).
- **모션**: 스톱모션 애니메이션 질감 (10~12fps), 통통 튀는 바운스.

### 10. 전통 수묵 / 모던 캘리그래피
- **적합 대상**: 전통문화, 한국적 감성, 클래식 브랜드의 디지털 전환 제품.
- **비주얼**: 먹물 번짐 효과, 한지 질감, 붉은 낙관 인장 포인트, 세로쓰기 타이포.
- **모션**: 수묵 번짐 마스크, 두루마리 펼침, 붓글씨 필획 애니메이션.

### 11. 키네틱 타이포그래피 (모션 텍스트)
- **적합 대상**: 시각 소재가 부족하지만 슬로건 한마디로 강렬한 인상을 남길 수 있는 제품; 다른 스타일의 브릿지 구간.
- **비주얼**: 텍스트만으로 구성, 폰트 크기·두께·배열의 급격한 변화로 시각적 충격 형성.
- **모션**: 단어 단위 팝업, 비트와 정확히 맞물리는 텍스트 밀어내기 및 줌 타격.

## 내러티브 구조

내러티브 역시 상황에 맞춰 고르는 메뉴입니다. 사용자에게 제안할 때는 **해당 제품에 맞춘 구체적인 스토리**로 제시해야 합니다.

| 구조 | 흐름 | 적합 대상 |
|---|---|---|
| 페인포인트 → 반전 → 증명 → CTA | "혹시 이런 문제로 골치 아프셨나요?" → "이제 딱 한 줄이면 끝납니다" → 폭발적인 기능/결과물/데이터 증명 → 사이트 주소 안내 | 대다수의 유틸리티 도구 및 튜토리얼 |
| 원테이크 제품 투어 | 카메라가 끊김 없이 제품의 여러 화면을 연속으로 가로지르며 탐색 | UI 디자인이 수려하고 기능 흐름이 매끄러운 SaaS |
| 캐릭터 페르소나 스토리 | 주인공 캐릭터의 문제 발생 → 제품 사용 → 일상/업무 혁신 | 친근한 대중 타깃 앱, Q버전 스타일 |
| 비포 & 애프터 비교 | 동일한 작업: 사용 전 vs 사용 후를 화면 분할 또는 순차 비교 | 업무 효율성 극대화 도구 |
| 압도적 데이터 폭격 | 놀라운 성과 지표 연속 노출 + 실제 증빙 화면 결합 | 스타 수, 누적 사용자 수가 뛰어난 오픈소스 및 플랫폼 |
| 타임어택 챌린지 | "10분 안에 앱 하나 뚝딱 만들기" 실시간 타이머 가속 연출 | 속도와 간편함을 극대화한 제품 |
| 유저 증언 및 커뮤니티 반응 | 실제 찬사 리뷰, 트윗 스크린샷, 커뮤니티 반응이 화면을 채움 | 실사용자 만족도가 검증된 제품 |
| 사건 폭로 / 핫이슈 프리뷰 | 무슨 일이 일어났는지 단숨에 설명 → "도대체 어떻게 된 일일까?" → 발견 경로 → 검증 → 유출 결과물 → 현재 공식 입장 → 사용자가 할 수 있는 일 | 신규 모델 비공식 유출, 화제의 사건 (Claude Fable 5.5 등) |

**수수께끼식 의문 제기가 명확한 설명을 대신할 수 없습니다**: 오프닝에서는 전문가만 아는 은어를 쓰지 말고, 누구나 단번에 이해할 수 있는 쉬운 일상어로 사건과 제품의 실체를 먼저 명확히 짚어주어야 합니다. 각 씬의 첫 내레이션은 이전 씬의 마지막 내용과 자연스럽게 맞물려야 시청자가 이탈하지 않습니다.

## 공통 품질 필수 체크포인트

- **스타일은 포장일 뿐, 실제 스크린샷이 주인공입니다**: 어떤 스타일을 채택하든 실제 제품 화면과 결과물이 노출될 메인 영역을 반드시 확보해야 합니다 (브라우저 프레임, 폰 목업, 만화 컷 등).
- **오프닝은 지체 없이 페인포인트나 핵심 강점으로 직행합니다**: 앰비언트 인트로나 배경 설명이 첫 3초를 낭비해서는 안 됩니다.
- **화면의 깊이감(레이어)**: 배경 레이어 / 메인 콘텐츠 레이어 / 전경 장식 요소를 분리하여 평면적인 느낌을 탈피합니다.
- **정적 상태와 동적 상태의 조화**: 정지 화면(데드 프레임)이 발생하지 않도록 각 씬마다 미세한 모션(미세 줌인, 부유 모션 등)을 유지합니다.
- **의도된 트랜지션**: 음악의 강한 비트와 맞물려 자연스럽게 화면을 전환합니다.
- **텍스트 대비 확보**: 배경색과 자막이 겹쳐 가독성을 해치지 않도록 항상 충분한 대비를 확보합니다.
