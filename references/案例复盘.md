# 案例复盘

这份文档记录用本工具交付过的 5 支宣传片。成片和工程不随仓库分发（体积大、含各自的素材和密钥），这里只留下对以后的项目有用的部分：每支片子为什么选这个风格、用户提了什么反馈、最后怎么改好的。

读它是为了学方法。**不要照搬任何一支的配色、版式、镜头和特效**，下一个产品要有它自己的答案。

---

## 1. Vibe Coding 教程宣传片

- **产品**：一套免费的 AI 编程零基础教程。
- **成片**：深色电影预告片风格，78 秒，4K60，含网页播放版。
- **经历**：4 轮反馈。第一版快切 0.45 秒、信息场景 3.6 秒，被评「太快、观众反应不过来」，于是有了 AGENTS.md 里的「节奏底线」。开场音乐从乐句中间切入，又垫了一段合成低频 drone，被评「音乐怪」，于是有了「小节线入场、不垫 drone」的规则。用户还指出「全片没有一个地方放完整网址」，于是网址必须出现在最高潮。
- **可以学的**：把真实应用界面分层重建成 React 组件，让它在画面里一块块「长出来」，比贴一张静态截图生动得多。

## 2. 编程导航宣传片

- **产品**：一个编程学习社区，有学习路线、项目教程、面试题和交流区。
- **成片**：浅色等距 3D 导航地图风格（代码绘制的 SVG 城市），60 秒，4K60 + 1080p60 + 网页版。
- **经历**：第二版是按「节奏慢、缺真实截图、配乐不搭」的反馈整体重做的。重做后改成痛点开场、3.9 秒就进入音乐爆发，登录后截了 10 张 4K 真实页面，项目快切每 2 拍切换一次画面。用户另外指出学习路线段放的是单个详情页，「应该展示出学习路线列表页面」，因为数量本身就是卖点。第三版起配乐、音效、旁白全部由 ElevenLabs 生成。
- **可以学的**：ElevenLabs 按分镜作曲后，用 `music` 拼接表在小节线上补长曲子；旁白用音色库的 Haoran（`pU9NaAwkoR3v0Mrg3uKz`，「广告」类，低沉有磁性），三个候选里只有它的开头句不用加速。网址单独转写是对的，混进音乐后被听成「点 CM」，加深那一句的 duck、减弱同时刻的闪光音效、`say` 里写成大写「C N」后才稳定。

`timing.json` 里音乐和旁白的真实写法（节选）：

```json
{
  "beat": 0.5453, "bar": 2.1812, "drop": 4.3624, "musicOffset": 3.3696,
  "music": [
    {"at": 0, "from": 3.3696, "to": 55.7184},
    {"at": 52.3488, "from": 46.9936, "to": 51.356},
    {"at": 56.7112, "from": 55.7184, "to": 58.56}
  ],
  "voice": {
    "voiceId": "pU9NaAwkoR3v0Mrg3uKz", "model": "eleven_v4", "language": "zh",
    "settings": {"stability": 0.45, "similarity_boost": 0.75, "use_speaker_boost": true},
    "rmsDb": -13, "duckDb": -9, "gain": 1.0,
    "lines": [
      {"id": "hook", "at": 0.35, "end": 4.25, "text": "从哪开始学？项目没亮点？面试总卡壳？"},
      {"id": "brand", "at": 4.65, "end": 8.6, "text": "编程导航，学路线、做项目、拿 Offer！"}
    ]
  }
}
```

`music` 表的意思是：视频第 `at` 秒开始，播放曲目的 `from`~`to` 段。第二段把中间 2 小节重复了一次，让曲子刚好撑满 60 秒，拼接点都落在小节线上。

## 3. 面试鸭宣传片

- **产品**：一个程序员面试刷题平台。
- **成片**：黑白热血漫画风（单一鸭黄点睛色），第 2 版 53.7 秒，4K60 + 1080p60 + 网页版。
- **经历**：第 2 版按「节奏慢、缺真实截图、AI 题不真实、配乐不搭」重做。开场直接连发 4 道站内浏览量最高的真实题目，ElevenLabs 按分镜作曲（两次爆发 + 中间回落，回落段放答案旁白）。旁白用的是作者本人的克隆音色，这个音色只训练了 `eleven_multilingual_v2`，stability 0.5 时「一万多道题」被听成「一模多刀」，调到 0.85 才稳定。
- **可以学的**：AI 生成漫画分格后用 Real-ESRGAN 4 倍超分，4K 下线条才不发软；通过官方公开接口抓了 283 个真实题库图标拼成图标墙；截图放进漫画墨框容器里推拉，风格和真实截图两不误。还有一次教训：「再精挑」在混音里被听成「带金条」，当时以为是 riser 音效盖住了人声就删了音效，事后对照发现真正起作用的是重新生成了一条咬字更清楚的录音（见 `配音.md` 第 5 节）。

## 4. 鱼皮 AI 导航宣传片

- **产品**：一个 AI 工具与资源导航网站。
- **成片**：明亮水下 Q 版风（以 logo 为原型的小鱼吉祥物 + 贴纸描边），66.3 秒，4K60 + 1080p60 + 纯音乐版 + 网页版。
- **经历**：这支改了 5 轮，问题最多，也留下了最多的规则：
  - 开头慢：痛点段从 9.3 秒压到 4 秒。
  - 缺网站截图：每个栏目用一个浏览器窗口滚动真实页面。知识库教程要登录才能看全文，用户在 AI 工具内置浏览器里登录后，用快照重渲染拿到 4K 图（`snapshot.js` 就是这时写的）。
  - 配乐两次自选被否：第一版选了童趣的「Kids」，第二版换成轻快流行，都不对。第三次拉开曲风出 6 首叠旁白的试听，用户一轮就定了 Mixkit 的「Better Times are Coming」。教训是配乐跟受众和产品走，不跟画风走。
  - 截图被压窄：Tailwind 给 `img` 加的 `max-width: 100%` 把放大的截图横向压扁，模板 `index.css` 已修复。
  - 品牌名读错 + 回音 + 音色不像：`multilingual_v2` 把「鱼皮 AI」连读成「鱼排」，句尾混响拖尾 90~360 ms；换成 `eleven_v3` 读准，再用语音转语音转回本人音色才解决（`voice.sts` 和 `voice.keywords` 都是这时加的）。
- **注意**：这个工程是旧模板复制的，旁白没有走 `vo`。以后的项目一律用模板的 `elevenlabs.py vo`，不要自己写生成脚本。

## 5. Claude Fable 5.5 宣传片

- **产品**：一个尚未官方发布、只在网友中灰度流传的 AI 模型版本。
- **成片**：泄密档案风（炭黑 + 牛皮纸 + 赭橙），60 秒，4K60 + 1080p60 + 网页版。这是一支「抢先看」：全片常驻「未经官方确认」标注。
- **经历**：3 轮反馈。作者本人的克隆音色被评「很多音调都有点怪」，换成音色库的 Haoran 后，混音转写从 0.968 提高到 1.000；开头用「标着 5.1，答的却不是它？」这样的谜语式悬念，不了解背景的人看不懂，改成按「是什么 → 怎么发现 → 怎么验证 → 作品 → 官方未确认」顺序讲；开头 4 秒塞了 3 个镜头、2 秒里推两个焦点，被评「太快，来不及看画面」，改成前 4 秒 2 个画面、每个焦点至少停 1.4 秒。
- **可以学的**：案例全部追到 X 原帖，用 `xgrab.py` 下载原图原视频，不登录也能截推文；每个案例标 `@作者 · 日期`，片尾列全部出处。作曲里计划好的安静段模型没给，用 `audiolib.muffle` 把那几小节低通闷住，做出「官方还没开口」的静场。

## 共同规律

把 5 支片子的反馈放在一起看，用户最在意的始终是这几件事：

1. **开头要快**。几乎每支片子的第一轮反馈都是「开头慢」。痛点或亮点必须在 3 秒内出现。
2. **要看到真东西**。重绘卡片、AI 生图再精致，也替代不了真实截图和真实作品。
3. **配乐要用户亲耳定**。AI 自选的配乐被否的次数最多，越早给试听越省事。
4. **讲清楚比悬念重要**。外行看不懂的开场，懂行的人觉得再妙也没用。
5. **克隆音色不一定是最优解**。用户本人的克隆音色常有音调怪、咬字不稳的问题，和音色库音色放在一起试听再定。
